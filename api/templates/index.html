Dataset Details

  • Dataset Name: Mobile Price Classification
  • Total Samples: 2,000 labelled devices
  • Features: 20 mobile hardware specifications
  • Target Variable: price_range (4 balanced classes)
  • Class 0: Low Cost (Budget entry level)
  • Class 1: Medium Cost (Mid-range daily driver)
  • Class 2: High Cost (Upper mid-range / performance)
  • Class 3: Very High Cost (Flagship premium tier)

Technology Stack

  • Backend API: FastAPI + Uvicorn ASGI Server
  • Machine Learning: Scikit-Learn, NumPy, Pandas
  • Validation: Pydantic v2 + Pandera
  • MLOps Tracking: MLflow Tracking & Model Registry
  • Frontend: Responsive Modern Dashboard (HTML5/CSS3/ES6)
  • DevOps: Docker, Kubernetes Manifests, GitHub Actions CI
